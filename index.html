Configuración rápida para Mac y Windows
  1. Instala Ollama.
  2. Abre Terminal o PowerShell y ejecuta ollama pull gemma3:4b.
  3. Autoriza el origen https://procesadordelta.github.io mediante OLLAMA_ORIGINS y reinicia Ollama.
  4. Vuelve aquí y pulsa Comprobar conexión.

Alternativa manual · usar otra IA sin conectar cuentas

La web no accede a tus cuentas ni aplicaciones. Tú eliges dónde adjuntar las imágenes; al enviarlas se aplican las condiciones de privacidad de esa IA.
